# Resume Project Description

### Project Title:
**Banking Customer, Transaction & Loan Analytics using SQL (MySQL 8+)**

---

## 3 High-Impact Resume Bullet Points

* **Engineered a 7-table normalized relational banking database** (5,000+ customers, 7,000+ accounts, 105,000+ transactions, 3,000+ loans) in **MySQL 8+**, implementing primary/foreign key constraints, check rules, and indexing to ensure ACID compliance and 100% data integrity.
* **Authored 38+ advanced analytical SQL queries** utilizing **CTEs, Window Functions (`DENSE_RANK`, `LAG`, `ROW_NUMBER`), Multi-Table JOINs, and conditional aggregations** to evaluate customer segmentation, MoM transaction growth velocity, branch deposit mobilization, and loan portfolio default indicators across ₹3.7B+ in customer deposits.
* **Conducted comprehensive credit risk and channel analytics**, identifying a 71.9% deposit concentration among top-tier wealth segments, uncovering a 64.1% transaction volume dominance across digital channels (UPI/Net Banking), and formulating data-backed asset allocation and portfolio monitoring recommendations for retail banking leadership.

- **Domain Competencies**: Retail Banking Analytics, Customer Wealth Segmentation, Asset Quality & Default Rate Tracking, Digital Payment Channel Adoption, Deposit-to-Loan Ratio Analysis, Branch Performance Scorecards
